# Third-party notices

No third-party code is included. The VTF reader in `src/vtf/` started as the reader of
[VTFBridge](https://github.com/haos9cr/VTFBridge) (same author, MIT).

## References

The VTF format handling was written from the public format description and checked against
VTFLib (Neil Jedrzejewski, Ryan Gregg; LGPL) and srctools (TeamSpen210; MIT). No code from
either is included. srctools and Pillow are used by the tests only.
