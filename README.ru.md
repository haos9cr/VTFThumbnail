# VTFThumbnail — эскизы VTF в проводнике Windows

[![tests](https://github.com/haos9cr/VTFThumbnail/actions/workflows/tests.yml/badge.svg)](https://github.com/haos9cr/VTFThumbnail/actions/workflows/tests.yml)

[English version](README.md)

Показывает текстуры **Valve Texture Format (`.vtf`)** — движок Source: Half-Life 2,
Counter-Strike: Source, Garry's Mod, Team Fortress 2, Portal, … — эскизами в проводнике Windows,
в диалогах открытия файлов и везде, где Windows показывает эскизы.

Небольшое 64-битное расширение оболочки (`IThumbnailProvider`). Без VTFLib, без других DLL, без
Visual C++ Redistributable. Родственный проект: [VTFExport](https://github.com/haos9cr/VTFExport) —
плагин VTF для Photoshop.

## Возможности

- VTF 7.0 – 7.5, почти все форматы: DXT1/3/5, DXT1 с 1-битной альфой, ATI1N/ATI2N, все 8-битные
  RGB(A)/BGR(A)/ABGR/ARGB/BGRX, 565/5551/4444, I8/IA88/A8, UV88/UVWQ/UVLX, bluescreen,
  HDR 16/32 бит (обрезается до 0..1).
- **Быстро на больших текстурах:** читается только заголовок и один мип-уровень — самый маленький
  из тех, что не меньше эскиза, — а не весь файл. Текстуры без мипмапов декодируются целиком
  (до 8192×8192).
- Чёткое и правильное уменьшение (усреднение по площади с учётом альфы — цвет прозрачных
  пикселей не «протекает»). Пропорции сохраняются, маленькие текстуры не растягиваются.
- **Альфа:** показывается как прозрачность, кроме карт нормалей и SSBump — там альфа служит маской
  (блик и т.п.), и эскиз выглядел бы полупустым. См. [Настройки](#настройки).
- Анимированные текстуры — кадр 1, кубмапы — первая грань, объёмные — первый срез.
- Битые и обрезанные файлы просто остаются без эскиза.

## Установка

1. Скачайте `VTFThumbnail-<версия>.zip` из [Releases](../../releases) и распакуйте туда, где он
   останется, например `C:\Program Files\VTFThumbnail\`. Проводник загружает DLL из этой папки,
   поэтому не перемещайте и не удаляйте её потом.
2. Запустите `install.cmd`:
   - *правый клик → Запуск от имени администратора* — для всех пользователей;
   - двойной клик — только для вашей учётной записи (права администратора не нужны).
3. Откройте папку с `.vtf` в режиме *Крупные значки*.

`install.cmd` просто выполняет `regsvr32 VTFThumbnail.dll`. Нужна 64-битная Windows 7 или новее
(рассчитано на Windows 10 / 11).

### Удаление / обновление

Запустите `uninstall.cmd` (от администратора, если ставили для всех), затем удалите папку. Если
Windows пишет, что DLL занята, сначала выйдите из системы и войдите снова (или перезапустите
проводник). Обновление: удалить, заменить DLL, установить снова.

Если до этого другая программа регистрировала свой обработчик эскизов `.vtf`, при удалении он
возвращается.

## Настройки

`HKEY_CURRENT_USER\Software\VTFThumbnail` (или `HKEY_LOCAL_MACHINE\…` для всех), `DWORD`:

| Значение | Что делает |
|---|---|
| `AlphaMode` = `0` | авто (по умолчанию): прозрачность, кроме карт нормалей / SSBump |
| `AlphaMode` = `1` | всегда показывать альфу как прозрачность |
| `AlphaMode` = `2` | всегда непрозрачно (альфа игнорируется) |

```
reg add HKCU\Software\VTFThumbnail /v AlphaMode /t REG_DWORD /d 2 /f
```

Windows кеширует эскизы: после смены настройки очистите кеш (*Очистка диска → Эскизы*), чтобы
уже открытые файлы перерисовались.

## Если не работает

- **Только значки, без эскизов** — *Параметры папок → Вид →* снимите *Всегда отображать значки,
  а не эскизы*; включите вид с крупными значками.
- **Старые / неверные эскизы** — очистите кеш эскизов (*Очистка диска → Эскизы*).
- **Всё равно ничего** — возможно, другая программа повесила свой обработчик на тип файла (ProgID).
  Посмотрите `HKEY_CLASSES_ROOT\.vtf` и раздел, указанный в его значении по умолчанию, — нет ли там
  подраздела `ShellEx\{E357FCCD-A995-4576-B01F-234630154E96}`, — и создайте
  [issue](../../issues) с тем, что нашли.

## Сборка

Visual Studio 2022 (или новее) с компонентом *Разработка классических приложений на C++*: откройте
`VTFThumbnail.sln`, выберите **Release | x64**, соберите. DLL: `bin\Release\VTFThumbnail.dll`.
`tools\make_release.ps1` упаковывает её со скриптами в `dist\VTFThumbnail-<версия>.zip`.

В Linux `./build.sh` собирает ту же DLL кросс-компилятором MinGW-w64.

### Тесты

```
pip install srctools pillow
tests/run_tests.sh          # код эскизов против srctools + Pillow, фаззинг с ASan/UBSan
tests/run_tests.sh --wine   # + настоящая DLL под Wine, как её вызывает проводник; regsvr32
```

### Структура

| | |
|---|---|
| `src/Thumbnail.*` | VTF → эскиз (переносимый код: выбор мипа, декодирование, уменьшение) |
| `src/ThumbnailProvider.cpp` | `IThumbnailProvider` + `IInitializeWithStream` |
| `src/Dll.cpp` | фабрика классов, экспорт DLL, регистрация через `regsvr32` |
| `src/vtf/` | читалка VTF без зависимостей (заголовок, поиск мипа, все декодеры) |
